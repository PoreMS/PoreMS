.. py:class:: Molecule(name='molecule', short='MOL', inp=None)

   This class defines a molecule object, which is basically a list of Atom
   objects combined with a numpy-backed positions list. Each atom object carries
   the atom type, name and residue; positions are stored separately for
   vectorised bulk operations.

   Functions have been provided for editing, moving and transforming the
   atom objects, either as a collective or specific part of the molecule.

   :param name: Molecule name
   :type name: string, optional
   :param short: Molecule short name
   :type short: string, optional
   :param inp: None for empty Molecule, string to read a molecule from a
               specified file link, or a list of Molecule objects to concatenate.
   :type inp: None, string, list, optional

   .. rubric:: Examples

   Following example generates a benzene molecule without hydrogen atoms

   .. code-block:: python

       import porems as pms

       mol = pms.Molecule("benzene", "BEN")
       mol.add("C", [0,0,0])
       mol.add("C", 0, r=0.1375, theta= 60)
       mol.add("C", 1, r=0.1375, theta=120)
       mol.add("C", 2, r=0.1375, theta=180)
       mol.add("C", 3, r=0.1375, theta=240)
       mol.add("C", 4, r=0.1375, theta=300)

   .. py:method:: bond(inp_a, inp_b)

      Return the bond vector of a specified bond. The two inputs can either
      be atom indices or positional vectors.

      :param inp_a: Either an atom id or a position vector
      :type inp_a: integer, list
      :param inp_b: Either an atom id or a position vector
      :type inp_b: integer, list

      :returns: **bond** -- Bond vector
      :rtype: numpy.ndarray

      .. rubric:: Examples

      .. code-block:: python

          mol.bond(0, 1)
          mol.bond(*[0, 1])
          mol.bond([1, 0, 0], [0, 0, 0])

   .. py:method:: add(atom_type, pos, bond=None, r=0, theta=0, phi=0, is_deg=True, name='', residue=0)

      Add a new atom in polar coordinates. The ``pos`` input is either
      an atom id that determines the bond-start, or a vector for a specific
      position.

      :param atom_type: Atom type
      :type atom_type: string
      :param pos: Position of the atom
      :type pos: integer, list
      :param bond: Bond axis
      :type bond: list, optional
      :param r: Bond length
      :type r: float, optional
      :param theta: Azimuthal angle
      :type theta: float, optional
      :param phi: Polar angle
      :type phi: float, optional
      :param is_deg: True if angles are given in degrees
      :type is_deg: bool, optional
      :param name: Unique atom name
      :type name: string, optional
      :param residue: Residue number
      :type residue: integer, optional

      .. rubric:: Examples

      .. code-block:: python

          mol.add("C", [0, 0, 0])
          mol.add("C", 0, r=0.153, theta=-135)
          mol.add("C", 1, [0, 1], r=0.153, theta= 135)
