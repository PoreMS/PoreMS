      Attach molecule on the surface.

      :param mol: Molecule object to attach

      :type mount: integer
      :param axis: List of two atom ids of the molecule that define the molecule axis

      :type amount: int
      :param site_type: Use **in** for the interior surface and **ex** for the exterior

      :param trials: Number of trials picking a random site
      :type trials: integer, optional
      :param is_proxi: True to fill binding sites in proximity of filled binding site
      :type is_proxi: bool, optional
      :param is_rotate: True to randomly rotate molecule around own axis
      :type is_rotate: bool, optional
      :param is_g: Force to add molecules only on single binding sites
      :type is_g: bool, optional

      :type is_sum: bool, optional

      :returns: **surface** -- Pore surface of interior and exterior
      :rtype: dictionary



   .. py:method:: allocation()

      Calculate molecule allocation on the surface. Using interior and
      exterior surfaces, the allocation rates can be determined by counting
      the number of used molecules on the surfaces.

      Using the conversion function :func:`porems.utils.mols_to_mumol_m2`, the
      number of molecules is converted to concentration in
      :math:`\frac{\mu\text{mol}}{\text{m}^2}`.

      :returns: **alloc** -- Dictionary containing the surface allocation of all molecules in
                number of molecules, :math:`\frac{\text{mols}}{\text{nm}^2}` and
                :math:`\frac{\mu\text{mol}}{\text{m}^2}`
      :rtype: dictionary

.. py:class:: PoreCylinder(size, diam, res=5, hydro=None)

   Bases: :py:obj:`PoreKit`


   This class carves a cylindrical pore system out of a
   :math:`\beta`-cristobalite block.

   :param size: Size of the silicon-oxygen-grid
   :type size: list
   :param diam: Cylinder diameter
   :type diam: float
   :param res: Reservoir size on each side
   :type res: float, optional
   :param hydro: Hydroxilation degree for interior and exterior of the pore in
                 :math:`\frac{\mu\text{mol}}{\text{m}^2}`
   :type hydro: list, optional

   .. rubric:: Examples

   Following example generates a cylindrical pore with a diameter of 4nm,
   reservoirs of 5nm on each side and a surface functionalized with TMS

   .. code-block:: python

       import porems as pms

       pore = pms.PoreCylinder([6, 6, 6], 4, 5)

       pore.attach(pms.gen.tms(), 0, [0, 1], 100, "in")
       pore.attach(pms.gen.tms(), 0, [0, 1], 20, "ex")

       pore.finalize()

       pore.store("output/")

.. py:class:: PoreMultiChannel(size, n_channels, diam, spacing=None, res=5, hydro=None)

   Bases: :py:obj:`PoreKit`


   Convenience class that carves *N* parallel cylindrical channels into a
   :math:`\beta`-cristobalite block.

   The channels are arranged in a regular 1-D row along the x-axis and share
   the same y-coordinate as the block centroid.  Their centre-to-centre
   spacing is ``spacing`` (defaulting to ``diam + 0.5`` nm).

   :param size: ``[nx, ny, nz]`` repeat counts for the BetaCristobalit block (nm).
   :type size: list
   :param n_channels: Number of parallel channels to carve.
   :type n_channels: int
   :param diam: Channel diameter in nm.
   :type diam: float
   :param spacing: Centre-to-centre channel spacing in nm.  Defaults to ``diam + 0.5``.
   :type spacing: float, optional
   :param res: Reservoir length on each side in nm (0 = no reservoir).
   :type res: float, optional
   :param hydro: Hydroxylation density ``[interior, exterior]`` in
                 :math:`\mu\text{mol}\,\text{m}^{-2}`.
   :type hydro: list, optional

   .. rubric:: Examples

   .. code-block:: python

       import porems as pms

       pore = pms.PoreMultiChannel([8, 4, 8], 3, 2.0, spacing=3.0, res=5)
       pore.attach(pms.gen.tms(), 0, [0, 1], 100, "in")
       pore.finalize()
       pore.store("output/multi/")


.. py:class:: PoreCone(size, diam_in, diam_out, res=5, hydro=None)

   Bases: :py:obj:`PoreKit`


   Convenience class that carves a conical pore into a β-cristobalite block.

   The cone transitions linearly from ``diam_in`` at one end to ``diam_out``
   at the other.  Both end diameters are on the interior surface.

   :param size: ``[nx, ny, nz]`` block repeat counts (nm).
   :type size: list
   :param diam_in: Diameter at the narrow end (nm).
   :type diam_in: float
   :param diam_out: Diameter at the wide end (nm).
   :type diam_out: float
   :param res: Reservoir length on each side (nm). Default 5.
   :type res: float, optional
   :param hydro: Hydroxylation density ``[interior, exterior]`` in μmol m⁻².
   :type hydro: list, optional

   .. rubric:: Examples

   .. code-block:: python

       import porems as pms

       pore = pms.PoreCone([8, 8, 10], 2.0, 4.0, res=5)
       pore.attach(pms.gen.tms(), 0, [0, 1], 100, "in")
       pore.finalize()
       pore.store("output/cone/")
